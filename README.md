# 🐍 Snake Game with Login System

A modern version of the classic Snake Game built using **HTML, CSS, and JavaScript**, enhanced with a **Login & Registration system** and deployed online.

---

## 🚀 Live Demo

🔗 https://snake-game-mocha-gamma.vercel.app

---

## ✨ Features

* 🔐 User Login & Registration (LocalStorage-based)
* 🎮 Classic Snake Game Mechanics
* ⚡ Dynamic speed increase
* 🍎 Food & Bonus Food system
* 🔊 Sound effects (eat & game over)
* 🏆 High score tracking
* 📱 Mobile responsive controls (touch + keyboard)
* 🎯 Difficulty levels (Easy, Medium, Hard)

---

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage (for auth & score)
* Deployment: Vercel

---

## 📂 Project Structure

```
snake-game/
│── index.html       # Login Page
│── game.html        # Main Game
│── signup.html      # Register Page
│── style.css        # Styling
│── script.js        # Game Logic
│── signup.js        # Register Logic
│── eat.mp3
│── over.mp3
```

---

## 🔑 How It Works

* Users can create an account and login
* User data is stored in **localStorage**
* Only logged-in users can access the game
* High score is stored and updated dynamically
